# 모의창업 IR 펀딩

학년·학과별 갤러리에 모둠과 IR 발표자료를 등록하고, 학생들이 가상 투자금으로 동시에 실시간 펀딩한 뒤 최다 펀딩 1위 팀을 발표하는 웹앱이에요.

- **사이트**: GitHub Pages (무료)
- **실시간 데이터**: Firebase Firestore (무료 Spark 요금제, 신용카드 필요 없음)
- **학생**: 아이디는 이름, 비밀번호는 학번으로 로그인 (선생님이 등록한 명단에 있어야 해요)
- **선생님(관리자)**: 관리자 아이디·비밀번호 또는 구글 계정으로 로그인

처음 한 번만 아래 순서대로 설정하면 돼요. 30분 정도 걸려요.

---

## 1. GitHub에 올리기

1. [github.com](https://github.com)에 로그인하고 오른쪽 위 **+ › New repository**를 눌러요.
2. 저장소 이름을 정해요. 예: `ir-funding`. **Public**으로 만들어요.
3. 만든 저장소에서 **uploading an existing file**을 눌러 이 폴더 안의 파일을 모두 끌어다 놓고 **Commit changes**를 눌러요.
   - `index.html`, `app.js`, `styles.css`, `firebase-config.js`, `firestore.rules`, `.nojekyll`, `decks` 폴더가 저장소 맨 위에 있어야 해요.
   - `.nojekyll`처럼 점으로 시작하는 파일이 안 보이면 그냥 넘어가도 돼요.
4. 저장소 **Settings › Pages**에서
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** 을 고르고 **Save**
5. 1~2분 뒤 `https://아이디.github.io/ir-funding/` 주소가 생겨요. 이 주소를 메모해 두세요.

## 2. Firebase 프로젝트 만들기

1. [console.firebase.google.com](https://console.firebase.google.com)에서 **프로젝트 추가**를 눌러요. (Google 애널리틱스는 꺼도 돼요.)
2. 프로젝트 첫 화면에서 웹 아이콘 **`</>`** 을 눌러 앱을 등록해요. (Hosting 설정은 체크하지 않아요.)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사해 두세요.

## 3. 로그인 방법 켜기

1. 왼쪽 메뉴 **빌드 › Authentication › 시작하기**
2. **로그인 방법** 탭에서
   - **익명** → 사용 설정 → 저장 (학생용)
   - **Google** → 사용 설정 → 프로젝트 지원 이메일 선택 → 저장 (선생님용)
3. **설정** 탭 › **승인된 도메인** › **도메인 추가**에 `아이디.github.io` 를 넣어요. (저장소 이름은 빼고 도메인만)

## 4. 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드 › Firestore Database › 데이터베이스 만들기**
2. 위치는 **asia-northeast3 (서울)**, **프로덕션 모드**로 시작해요.
3. **규칙** 탭을 열고, 이 저장소의 `firestore.rules` 내용을 전부 복사해 붙여넣어요.
4. 맨 위의 `adminEmails()` 안 `teacher@example.com`을 **선생님 구글 계정 이메일(소문자)** 로 바꾸고 **게시**를 눌러요.

## 5. 설정 파일 고치기

GitHub 저장소에서 `firebase-config.js`를 열고 연필 아이콘(Edit)을 눌러요.

1. `firebaseConfig` 안의 값을 2단계에서 복사한 값으로 바꿔요.
2. `ADMIN_EMAILS` 의 `teacher@example.com`을 4단계와 **같은 이메일**로 바꿔요.
3. **Commit changes**를 누르고 1~2분 기다려요.

> `apiKey`가 공개 저장소에 올라가도 괜찮아요. Firebase 웹 설정값은 원래 공개용이고, 실제 보호는 4단계의 보안 규칙이 맡아요.

## 6. 행사 준비하기

1. 사이트 주소를 열고 맨 아래 **관리자 로그인** → 선생님 구글 계정으로 로그인해요.
2. **운영** 탭
   - **1인당 투자금**과 투자 단위를 입력하고 저장해요.
   - **운영 규칙**에서 행사 이름, 투자 범위(내 갤러리만/전체), 학생 화면 실시간 금액 공개 여부를 정해요.
3. **갤러리·팀** 탭
   - **갤러리 만들기**로 펀딩 대상 학년·학과를 만들어요. 예: 2학년 경영과
   - 갤러리마다 **팀 등록**으로 모둠 이름, 아이템, 소개, 팀원, 발표자료 주소를 넣어요.
4. **학생 명단** 탭
   - **명단 붙여넣기**에서 갤러리를 고르고, 한 줄에 한 명씩 `학번 이름 팀이름`을 붙여넣어요. 엑셀에서 세 열을 복사해도 돼요.
   - 팀 이름이 맞으면 그 학생은 자기 팀에 투자할 수 없어요.

### 발표자료 넣는 방법

| 방법 | 발표자료 주소에 적을 내용 |
| --- | --- |
| PDF를 저장소에 올리기 (추천) | `decks/team3.pdf` — 저장소 `decks` 폴더에 PDF를 업로드 |
| 구글 슬라이드 | 공유 링크 그대로. 공유 설정은 ‘링크가 있는 모든 사용자 · 뷰어’ |
| 구글 드라이브의 PDF | 공유 링크 그대로. 공유 설정은 위와 같음 |
| 캔바 | ‘공개 보기 링크’ 그대로 |
| 슬라이드 이미지 여러 장 | `decks/team3-01.png` 처럼 한 줄에 하나씩 |

## 7. 행사 당일 진행

1. 학생들에게 사이트 주소(또는 QR 코드)를 알려 줘요. 학생은 **학생 로그인**에서 아이디에 이름, 비밀번호에 학번을 입력해요.
2. 관리자 **운영** 탭에서 **펀딩 시작** → 학생들이 동시에 투자해요.
3. 펀딩하는 동안 **관리자 화면이나 발표 화면을 켜 두세요.** 관리자 화면이 몇 초마다 집계해서 학생 화면의 금액·순위를 갱신해요. (학생 본인의 잔액·투자 내역은 바로 반영돼요.)
4. **펀딩 마감** → 그 순간 결과가 확정되고, 이후 들어오는 투자는 데이터베이스가 거부해요.
5. **발표 화면**을 프로젝터에 띄우고 **결과 발표**를 누르면 모든 학생 화면에 카운트다운과 1위 팀이 공개돼요.
6. **결과** 탭에서 갤러리별 순위와 전체 1위를 보고 **결과 CSV 저장**으로 내려받을 수 있어요.

### 이럴 때는

- **학생이 기기를 바꿨어요**: 새 기기에서 이름·학번으로 다시 로그인하면 돼요. 투자 기록은 그대로 이어지고, 이전 기기는 자동으로 로그아웃돼요.
- **로그인이 안 된대요**: 학생 명단의 이름·학번과 똑같이 입력했는지 확인하세요. 이름의 띄어쓰기는 무시돼요.
- **투자금을 바꾸고 싶어요**: 펀딩 중에도 올릴 수 있어요. 줄일 때는 가장 많이 투자한 학생의 금액보다 적게 줄일 수 없어요.
- **다시 처음부터 하고 싶어요**: **운영 › 투자 기록 초기화**
- **관리자 로그인 창이 안 떠요**: 카카오톡 같은 앱 안 브라우저가 아니라 크롬·사파리에서 여세요. 3단계의 승인된 도메인도 확인하세요.

## 동시 접속과 안전장치

- 학생마다 **자기 투자 기록 문서 하나**에만 쓰고, 그 쓰기는 트랜잭션으로 처리돼요. 여러 명이 같은 순간에 같은 팀에 투자해도 서로 덮어쓰지 않아요.
- 보안 규칙이 막는 것:
  - 다른 학생 기록 수정
  - 펀딩 기간이 아닐 때 투자
  - 우리 팀에 투자
  - 등록 정보와 다른 갤러리로 투자
  - 설정·팀·결과 변경 (관리자 외)
  - 다른 학생 이름 열람
  - 명단에 없는 이름·학번으로 로그인
- 한도 초과처럼 규칙으로 막을 수 없는 조작(개발자 도구로 직접 요청을 보내는 경우)은 집계에서 자동으로 빠지고, 관리자 **결과** 탭에 표시돼요.

## 무료 사용량 안내

Firestore 무료 한도는 하루 **읽기 5만 회, 쓰기 2만 회**예요.

- 쓰기: 학생 투자 횟수 + 집계 갱신 정도라 걱정할 필요 없어요.
- 읽기: 대략 `학생 수 × 펀딩 시간(초) ÷ 갱신 간격(초)` 이 최대치예요.
  - 예: 100명 × 20분(1,200초) ÷ 4초 = 약 3만 회
- 학생이 더 많거나 시간이 길면 `firebase-config.js`의 `SUMMARY_INTERVAL_SEC`를 6~10으로 늘리거나, 실시간 금액 공개를 끄세요. 끄면 결과 발표 전까지 학생 화면이 집계를 읽지 않아요.

## 파일 구성

| --- | --- |
| `index.html` | 페이지 뼈대 |
| `styles.css` | 디자인 |
| `app.js` | 앱 기능 전체 |
