# 발표자료 폴더

모둠의 IR 발표자료(PDF 또는 슬라이드 이미지)를 이 폴더에 올리세요.

- GitHub 저장소에서 `decks` 폴더를 열고 **Add file › Upload files**로 올리면 돼요.
- 관리자 화면 › 갤러리·팀 › 팀 등록에서 발표자료 주소에 `decks/파일이름.pdf`처럼 적으세요.
- 파일 이름은 영어·숫자로 짓는 것이 가장 안전해요. 예: `2-business-team3.pdf`
- 슬라이드를 이미지로 내보냈다면 한 줄에 하나씩 적으면 넘겨 보기가 돼요.

```
decks/team3-01.png
decks/team3-02.png
decks/team3-03.png
```

GitHub에 올린 파일은 누구나 볼 수 있어요. 개인정보가 들어간 자료는 올리지 마세요.
